Curso CESAR — Redes Open RAN · Projeto Prático (Parte 2)

Orquestração cloud-native para Open RAN, construída e operando sobre Nephio.

Uma implementação completa de automação de infraestrutura e ciclo de vida de funções de rede: provisionamento de O-Cloud via O2 IMS, entrega contínua de pacotes via GitOps, configuração de NF em duas camadas sincronizadas, monitoramento por métrica e uma função de otimização não-tempo-real (rApp) tomando decisões de capacidade em produção.

“Nephio is a cloud-native automation and orchestration platform that can implement or support functions associated with the SMO and O-Cloud management architecture.” — posicionamento oficial do projeto Nephio (Linux Foundation Networking), adotado como referência de escopo deste trabalho.

Um intent declarativo materializa um cluster Kubernetes completo através da cadeia ProvisioningRequest → Cluster API → CAPD.

02 · Entrega

Orquestração de pacotes

Pacotes versionados no Porch, publicados via GitOps e reconciliados continuamente no O-Cloud — sem intervenção manual.

Gestão de funções de rede

Instanciação, escala, atualização, recuperação e remoção — todas pelo mesmo mecanismo declarativo do Kubernetes.

Um rApp de capacidade observa telemetria em tempo não-real e decide escala de forma autônoma.

Avaliação técnica

Cobertura das funções de SMO pela proposta Nephio

Avaliação qualitativa da profundidade de implementação demonstrada neste projeto para cada função de gerência e orquestração, com base nos mecanismos exercitados e resultados obtidos nos 10 experimentos.

O Nephio se destaca como plataforma de automação para as funções ligadas a infraestrutura e ciclo de vida cloud-native — provisionamento, orquestração declarativa e gestão de lifecycle atingem cobertura completa neste projeto. Configuração e monitoramento têm cobertura substancial, com mecanismos próprios que preenchem a lacuna nativa da plataforma. A função de Non-RT RIC foi demonstrada de forma funcional através de um rApp de otimização autônoma, representando o primeiro passo de uma frente de expansão natural do projeto.

Esta leitura confirma o posicionamento do próprio projeto Nephio: uma plataforma de automação cloud-native que implementa e apoia funções associadas à arquitetura de SMO — não uma implementação certificada da especificação O-RAN Alliance como um todo, mas uma base sólida e extensível sobre a qual essas funções podem ser construídas.

Roadmap

Próximas frentes de evolução

Extensões naturais da arquitetura atual, priorizadas pelo valor que agregam à cobertura de funções de SMO.

→

Integração O1 (NETCONF/YANG)

Terminação da interface O1 para gerência FCAPS direta de elementos de rede, complementando a camada de configuração já existente.

→

Federação com Near-RT RIC

Publicação de políticas A1 para um Near-RT RIC dedicado, evoluindo o rApp atual de ação direta para o modelo de política padrão O-RAN.

→

Expansão do config-bridge

Generalização da sincronização configuração↔pacote para todas as funções de rede e campos de domínio.

→

Telemetria O-RAN nativa

Adoção de VES/PM Jobs para alinhamento com os formatos de telemetria padronizados pela O-RAN Alliance.

→

Funções de rede de referência

Avaliação já conduzida (free5GC, UERANSIM, OpenAirInterface) como base para uma futura integração com carga computacional dedicada.

→

Federação multi-O-Cloud (FOCOM)

Extensão do modelo de provisionamento para múltiplos O-Clouds geridos por um SMO federado.
